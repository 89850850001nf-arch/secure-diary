# 🔒 Секретный Дневник (Secure Diary)

Это мой первый проект на Python (Flask) с упором на безопасность.

## 🛡️ Реализованные защиты:
*   Защита от SQL-инъекций (параметризованные запросы).
*   Защита от XSS (экранирование HTML).
*   Защита от CSRF (токены).
*   Безопасное хеширование паролей (werkzeug).
*   Защита от IDOR (доступ только к своим записям).

## 🚀 Как запустить:
1. Установите Flask: `pip install flask`
2. Запустите: `python3 app.py`
